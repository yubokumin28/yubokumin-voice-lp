📌 結論 — このLPは AI社員のリレーではなく、Claude Codeが「単独で直接ビルド」しました。
建設LP(社員バケツリレー)とは作り方が根本的に違い、1人の作り手が約1週間かけて、コミットを重ねて磨いたものです。本格3Dエンジン(React Three Fiber)採用で、技術的には建設LPより重厚です。

② 単独ビルド or 分担？ → 単独（Claude Codeが直接）

建設LPのような「秘書→開発→検品」の社員リレーは使っていません。1つのリポジトリを直接編集し、git pushでVercelが自動デプロイ、という作り手1人＋自動公開の構成です。
💡 比べると面白い点: 建設LPは「AIの会社が分担(逐次リレー)」、音声LPは「Claude Codeが単独で全部」。どちらも並列ではないのは共通ですが、体制がまるで違います。

③ 何を・どんな技術で作ったか

建設LPが「単一HTML＋軽量3D表示」だったのに対し、音声LPはNext.jsの本格構成＋3Dエンジンを自前で動かす重厚な作り。

📝 内容・構成

ヒーロー(製品名Grow Voice主役)→ベネフィット→使い方(how)→実画面(live・ツール4枚)→声の波形→育つ辞書(learn)→お客様の声(testi)→CTA→フッター。別ページに/download(配布)。

🦭 3Dモデル（本格エンジン）

React Three Fiberthree.js@react-three/drei
自前の3Dシーン(Orb3D・ScrollScene)を<Canvas>で描画し、useGLTFで seal.glb(あざらし) を読込。建設LPと同じあざらしモデルを再利用(3DはAI制作でなく既存資産)。

🎬 アニメーション

GSAP + GSAP ScrollTrigger + Framer Motion。
スクロール量に3D/要素を連動させる本格モーション。building LPの「素のCSS」より高機能。

🖱️ スクロール体感

Lenis(慣性スムーススクロール)＋ ScrollTrigger でスクロール駆動の3Dシーン(ScrollScene)。`.reveal`の段階表示も併用。

🔘 ボタン・UI

ガラス質(グラスモーフィズム)の自作UI: GlassButton / LiquidGlassCard / VoiceWave(声の波形)。
/download にOS別2ボタン＋3SNS横並びのワンクリック共有(ShareButtons)。

🖼️ 画像（自前で用意）

Unsplashではなく自前画像。海/砂/夜明け/海中の背景(bg-ocean/sand/dawn/shore・cta-underwater)、実アプリのスクショ4枚(tool-dict/record/settings/visual)、あざらし(seal-hero/seal-logo/swimming/story)。

🔤 フォント

Geist / Geist Mono を自己ホスト(woff同梱)。外部フォントCDNに頼らない。

🚀 ホスティング/配布

Vercel(main push で自動デプロイ)。/download から GrowVoice Windows/Mac の配布ZIP(public/downloads)を直接DL。

⑤ 2つのLPを並べて比較

🏗️ 建設LP（azarashi-lp）

  • 体制: AI社員の逐次リレー(CEO→秘書→開発⇄検品)
  • 土台: 単一HTMLファイル
  • 3D: model-viewer(軽量タグ表示)
  • 演出: 素のCSS/JS(IntersectionObserver)
  • 画像: Unsplash(無料ストック)
  • フォント: なし(OS標準)

🎤 音声LP（Grow Voice）

  • 体制: Claude Codeが単独ビルド＋Vercel自動公開
  • 土台: Next.js 14(本格構成)
  • 3D: React Three Fiber(自前3Dエンジン)
  • 演出: GSAP + Lenis + Framer Motion
  • 画像: 自前(海・実画面・あざらし)
  • フォント: Geist(自己ホスト)
🦭 共通点: あざらしの3Dモデル(seal.glb)は両方で再利用。どちらもAIが3Dを作ったのではなく、用意済みの資産を組み込んでいます。並列処理を使っていないのも共通です。
